# Object-Oriented Programming in Python

Learning OOP in Python through examples.

### Topics

- Classes and objects
- Constructors and `self`
- Class and instance attributes
- Instance, class and static methods
- Inheritance and `super()`
- Assertions
- `__repr__()`
- Reading data from CSV files

I've been practising these concepts by building classes such as `Item` and `Phone` and experimenting with their attributes and methods.
